# Application Security Verification Standard (ASVS)

The OWASP ASVS control implementation for this base template maps against
the [OWASP Application Security Verification Standard (ASVS) 5.0.0](https://github.com/OWASP/ASVS/tree/v5.0.0/5.0).
It is a planning and verification aid, not an ASVS conformance claim.

The control implementation covers the application and the security capabilities intentionally supplied by this template. It does not certify the application that an adopter builds from it, its identity provider, data stores, deployment platform, networks, monitoring stack, or operational procedures. Each template adopter must reassess the rows when adding features or choosing a deployment topology.

The tables contain all 345 ASVS 5.0.0 requirements. Requirement text is reproduced from OWASP ASVS 5.0.0, which is licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Use version-qualified identifiers such as `v5.0.0-1.1.1` in evidence, tickets, and test cases so a later ASVS version can't silently change the requirement being referenced.

For the template's related evidence, see [Authentication](authentication.md), [Authorization](authorization.md), [Sessions](sessions.md), [HTTP security headers](headers.md), [Error responses](error-responses.md), [Logging](../06-logging-and-monitoring/README.md), [Logging schema](../06-logging-and-monitoring/schema.md), and the [CIS Tomcat Benchmark control implementation](hardening.md).
