# Security and API error responses

The API returns RFC 9457 Problem Details (`application/problem+json`). Clients
must use the `type` URI as the stable, machine-readable error identifier; the
HTTP status, title, detail, and `errors` extension provide supporting context.
The URNs below are a public compatibility contract. Do not rename an existing
type after a client can consume it.

| Type | HTTP status | Description | Generated by |
| --- | --- | --- | --- |
| `urn:problem:validation-failed` | 400 | One or more request values fail validation, including Bean Validation failures, `ConstraintViolationException`, a deliberate `BadRequestException`, and any other `IllegalArgumentException`. The optional `errors` extension identifies field-level failures where known. A correlated, redacted `validate_input` audit event records the rule and field/path, never the rejected value or exception message. | [`ApiResponseEntityExceptionHandler:41`](../src/main/java/com/example/app/web/server/api/ApiResponseEntityExceptionHandler.java#L41) |
| `urn:problem:malformed-request` | 400 | The request body cannot be read as the expected content. A correlated, redacted `validate_input` audit event records the safe `MalformedRequest` code, not request content. | [`ApiResponseEntityExceptionHandler:61`](../src/main/java/com/example/app/web/server/api/ApiResponseEntityExceptionHandler.java#L61) |
| `urn:problem:resource-not-found` | 404 | A domain resource referenced by the request does not exist. | [`ApiResponseEntityExceptionHandler:94`](../src/main/java/com/example/app/web/server/api/ApiResponseEntityExceptionHandler.java#L94) |
| `urn:problem:route-not-found` | 404 | No application route matches the request. | [`ApiResponseEntityExceptionHandler:153`](../src/main/java/com/example/app/web/server/api/ApiResponseEntityExceptionHandler.java#L153) |
| `urn:problem:method-not-allowed` | 405 | The route exists but does not support the HTTP method. | [`ApiResponseEntityExceptionHandler:159`](../src/main/java/com/example/app/web/server/api/ApiResponseEntityExceptionHandler.java#L159) |
| `urn:problem:resource-conflict` | 409 | The requested domain change conflicts with existing state. | [`ApiResponseEntityExceptionHandler:100`](../src/main/java/com/example/app/web/server/api/ApiResponseEntityExceptionHandler.java#L100) |
| `urn:problem:upstream-response-failed` | Upstream status | An upstream HTTP dependency returned an error. The response does not expose its detail. | [`ApiResponseEntityExceptionHandler:133`](../src/main/java/com/example/app/web/server/api/ApiResponseEntityExceptionHandler.java#L133) |
| `urn:problem:internal-error` | 500 | An unexpected application failure occurred. Internal details are logged but never returned. | [`ApiResponseEntityExceptionHandler:145`](../src/main/java/com/example/app/web/server/api/ApiResponseEntityExceptionHandler.java#L145) |
| `urn:problem:session-expired` | 401 | A session expired after another login for the same user. The generic detail does not disclose device, location, or login timing. Returned to non-browser/API clients; browser navigation redirects to `/login?session-expired`. | [`ContentNegotiatingSessionExpiredStrategy:18`](../src/main/java/com/example/app/web/server/security/session/ContentNegotiatingSessionExpiredStrategy.java#L18) |
| `urn:problem:access-denied` | 403 | The authenticated request is not authorized for the operation. | [`ProblemDetailAccessDeniedHandler:26`](../src/main/java/com/example/app/web/server/security/authorization/ProblemDetailAccessDeniedHandler.java#L26) |
| `urn:problem:csrf-validation-failed` | 403 | The CSRF token could not be verified; the client can refresh and retry. | [`ProblemDetailAccessDeniedHandler:29`](../src/main/java/com/example/app/web/server/security/authorization/ProblemDetailAccessDeniedHandler.java#L29) |
| `urn:problem:http-error` | 4xx or 5xx | Tomcat rejected or failed the request before Spring MVC could produce a more specific response. | [`TomcatProblemDetailErrorReportValve:95`](../src/main/java/com/example/app/web/server/config/TomcatConfiguration.java#L95) |

The type constants live in
[`ProblemTypes`](../src/main/java/com/example/app/web/server/api/ProblemTypes.java).
