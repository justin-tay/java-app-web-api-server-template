# ISO/IEC 25010:2023 quality characteristics

This document summarizes the ISO/IEC 25010:2023 product-quality model. The model defines nine quality characteristics and their subcharacteristics for specifying, measuring, and evaluating ICT and software product quality, see [ISO/IEC 25010:2023](https://www.iso.org/obp/ui/#iso:std:iso-iec:25010:ed-2:v1:en).

## Quality characteristics

| Quality characteristic | Paraphrased definition |
| --- | --- |
| Functional suitability | How well a product's functions meet stated and implied needs in specified use conditions. |
| Performance efficiency | How effectively a product performs relative to the resources consumed under stated conditions. |
| Compatibility | How well a product can exchange information with, or share an environment and resources with, other products. |
| Interaction capability | How well a product enables users to interact with it to accomplish tasks in stated use conditions. |
| Reliability | How consistently a product delivers the required functions and performance for a stated time and under stated conditions. |
| Security | How well a product protects information and data so authorized people or systems have appropriate access. |
| Maintainability | How effectively and efficiently a product can be changed by its intended maintainers. |
| Flexibility | How effectively and efficiently a product can be adapted for changing hardware, software, operational, or usage environments. |
| Safety | How well a product avoids harm to people, property, or the environment in stated conditions. |

## Quality subcharacteristics

| Parent characteristic | Quality subcharacteristic | Paraphrased definition |
| --- | --- | --- |
| Functional suitability | Functional completeness | The degree to which the provided functions cover all specified tasks and objectives. |
| Functional suitability | Functional correctness | The degree to which functions produce correct results at the required precision. |
| Functional suitability | Functional appropriateness | The degree to which functions help users complete specified tasks and objectives effectively. |
| Performance efficiency | Time behaviour | The degree to which response, processing, and throughput times meet requirements. |
| Performance efficiency | Resource utilization | The degree to which resource amounts and types used meet requirements. |
| Performance efficiency | Capacity | The degree to which maximum limits for product parameters meet requirements. |
| Compatibility | Co-existence | The degree to which a product can perform its functions efficiently while sharing an environment and resources with other products. |
| Compatibility | Interoperability | The degree to which two or more products can exchange information and use the exchanged information. |
| Interaction capability | Appropriateness recognizability | The degree to which users can recognize whether a product is appropriate for their needs. |
| Interaction capability | Learnability | The degree to which users can learn to use a product effectively, efficiently, safely, and satisfactorily. |
| Interaction capability | Operability | The degree to which users can operate and control a product effectively, efficiently, and satisfactorily. |
| Interaction capability | User error protection | The degree to which a product protects users against making errors. |
| Interaction capability | User engagement | The degree to which a product's interaction is engaging and satisfying for users. |
| Interaction capability | Inclusivity | The degree to which a product can be used by people with diverse characteristics and capabilities. |
| Interaction capability | User assistance | The degree to which assistance enables users to use a product effectively, efficiently, safely, and satisfactorily. |
| Interaction capability | Self-descriptiveness | The degree to which a product makes its functions and usage understandable without unnecessary interaction. |
| Reliability | Faultlessness | The degree to which a product operates without faults under stated conditions for a stated period. |
| Reliability | Availability | The degree to which a product is operational and accessible when it is required for use. |
| Reliability | Fault tolerance | The degree to which a product continues intended operation despite hardware or software faults. |
| Reliability | Recoverability | The degree to which a product can recover affected data and restore its intended state after interruption or failure. |
| Security | Confidentiality | The degree to which information is accessible only to authorized users. |
| Security | Integrity | The degree to which a product prevents unauthorized access to, or modification of, programs and data. |
| Security | Non-repudiation | The degree to which actions or events can be proven so they cannot later be credibly denied. |
| Security | Accountability | The degree to which actions of an entity can be traced uniquely to that entity. |
| Security | Authenticity | The degree to which the identity of a subject or resource can be shown to be the claimed identity. |
| Security | Resistance | The degree to which a product sustains intended operation while under attack. |
| Maintainability | Modularity | The degree to which a product is composed of discrete components so changes to one have minimal effect on others. |
| Maintainability | Reusability | The degree to which a product asset can be used in more than one system or to build other assets. |
| Maintainability | Analysability | The degree to which the impact of a change or the cause of a failure can be assessed effectively and efficiently. |
| Maintainability | Modifiability | The degree to which a product can be changed effectively and efficiently without introducing defects or degrading quality. |
| Maintainability | Testability | The degree to which test criteria can be established and tests can be performed effectively and efficiently. |
| Flexibility | Adaptability | The degree to which a product can be adapted effectively and efficiently for different or evolving environments. |
| Flexibility | Scalability | The degree to which a product can handle changing demands by adjusting its capacity. |
| Flexibility | Installability | The degree to which a product can be installed or uninstalled successfully in a specified environment. |
| Flexibility | Replaceability | The degree to which a product can replace another specified product for the same purpose in the same environment. |
| Safety | Operational constraint | The degree to which a product restricts operation to conditions that avoid unacceptable risk. |
| Safety | Risk identification | The degree to which a product identifies conditions that can create unacceptable risk. |
| Safety | Fail safe | The degree to which a product moves to, and remains in, a safe state when a failure occurs. |
| Safety | Hazard warning | The degree to which a product warns relevant parties of hazardous conditions in time to reduce risk. |
| Safety | Safe integration | The degree to which a product can be integrated safely with other systems or components. |
