# Security logging event reference

This is the event-level contract for the ECS JSON events emitted by this
application. It complements [security-logging-schema.md](security-logging-schema.md),
which defines the shared ECS fields, project extensions, redaction rules, and
field types.

## Runtime and ECS Base fields emitted for every event

ECS defines a broader [Base field set](https://www.elastic.co/docs/reference/ecs/ecs-base).
The table below is deliberately narrower: it documents only the Base/runtime
fields emitted by this application through Spring Boot's ECS formatter. It is
not a claim that every ECS Base field is present.

| Field | Source | Meaning | ECS alignment |
| --- | --- | --- | --- |
| `@timestamp` | ECS formatter | Time at which the log event is emitted. | ECS Base field |
| `message` | Application logger | Human-readable message; use structured fields for querying. | ECS Base field |
| `log.level` | Application logger | Logger severity, such as `INFO`, `WARN`, or `ERROR`. | ECS Base field |
| `log.logger` | Application logger | Java logger name that emitted the event. | ECS Log field |
| `process.pid` | Runtime | JVM process identifier. | ECS Process field |
| `process.thread.name` | Runtime | Thread that emitted the event. | ECS Process field |
| `service.name` | `spring.application.name` | Logical application/service name. | ECS Service field |
| `service.environment` | Profile configuration | Deployment environment, such as `production`, `local`, or `test`. | ECS Service field |
| `ecs.version` | ECS formatter | ECS version used to encode the event. | ECS field |

All event sections below include these fields in addition to the listed
event-specific fields. The [schema document](security-logging-schema.md)
defines their ECS types, project extensions, correlation, and redaction rules.

For request-scoped events, `SecurityLoggingContextFilter` also puts `source.ip`
in MDC. It is the direct peer address from `HttpServletRequest.getRemoteAddr()`,
not a unique correlation identifier and not a proxy-normalized end-user IP.
When `WebSecurityConfiguration` is changed to supply a trusted
`ClientIpResolver`, it also adds `client.ip`. The supplied resolvers support a
normalized header, an `X-Forwarded-For` chain, and CloudFront's address-and-port
header; each rejects an untrusted immediate peer.

## Request lifecycle

## Request received: `receive_request`

Generated by `RequestLoggingFilter` when a request enters the application.
Level: `INFO`. It has no response outcome because processing has not completed.

| Field | Value or presence | Meaning | ECS alignment |
| --- | --- | --- | --- |
| `event.category` | `["web"]` | Event is a web request. | `web` is an allowed ECS category |
| `event.type` | `["access", "start"]` | Access lifecycle start. | `access` is expected; `start` is allowed |
| `event.action` | `receive_request` | Stable identifier for receiving a request. | ECS field; project-defined action |
| `event.start` | UTC instant | Time at which the filter received the request. | ECS Event field |
| `http.request.id` | Conditional | Correlation ID from `SecurityLoggingContextFilter`, generated as a UUID unless the selected `RequestIdResolver` supplies an upstream ID. | ECS HTTP field |
| `http.request.method` | Servlet method | Incoming HTTP method. | ECS HTTP field |
| `source.ip` | Every event | Direct peer address. It may be a proxy rather than the end user. | ECS Source field |
| `client.ip` | Conditional | Validated end-user client address from the configured `ClientIpResolver`. | ECS Client field |
| `url.scheme` | Every event | Request scheme as observed by the application. | ECS URL field |
| `server.address` | Every event | Request destination address as observed by the application. | ECS Server field |
| `server.port` | Every event | Request destination port as observed by the application. | ECS Server field |
| `url.path` | Every event | Request path as observed by the application. | ECS URL field |
| `url.query` | Conditional | Redacted query string when a query exists. | ECS URL field |
| `url.query_keys` | Conditional | Names of query parameters when a query exists. | Project extension |
| `user.name` | Conditional | Authenticated principal known when the request begins. | ECS User field |

## Request validation

## Input validation failed: `validate_input`

Generated by `ApiResponseEntityExceptionHandler` for rejected request-body and
method-parameter validation, malformed request content, and application input
validation represented by `IllegalArgumentException`. Level: `WARN`. It emits
one event for each failed Bean Validation field or constraint. Rejected values,
request bodies, exception messages, and validation messages are never logged.

| Field | Value or presence | Meaning | ECS alignment |
| --- | --- | --- | --- |
| `event.category` | `["web"]` | Failure occurred while validating a web request. | `web` is an allowed ECS category |
| `event.type` | `["error"]` | Input validation failure classification. | `error` is an allowed ECS type |
| `event.action` | `validate_input` | Request input validation operation. | ECS field; project-defined action |
| `event.outcome` | `failure` | Input was rejected. | ECS Event field |
| `http.response.status_code` | `400` | Status emitted for the rejected input. | ECS HTTP field |
| `url.path` | Every event | Request path; it must not contain secrets. | ECS URL field |
| `source.ip` | Every event | Direct peer address. It may be a proxy rather than the end user. | ECS Source field |
| `client.ip` | Conditional | Validated end-user client address from the configured `ClientIpResolver`. | ECS Client field |
| `error.type` | Validation exception class | Technical validation mechanism. | ECS Error field |
| `error.code` | Validation rule code | Bean Validation constraint name or a safe application code such as `MalformedRequest` or `InvalidRequest`. | ECS Error field |
| `validation.field` | Conditional | Rejected field or parameter path. Omitted when the parser or application cannot safely identify a field. | Project extension |

## Session lifecycle

Generated by `SessionLifecycleAuditLogger`. Level: `INFO`. These events are
limited to lifecycle causes the application can state accurately. They are not
emitted for JDBC idle cleanup or arbitrary invalid-cookie attempts.

## Request processing failures

## Request processing failed: `process_request`

Generated by `ApiResponseEntityExceptionHandler` for unexpected application
exceptions and upstream 5xx responses. Level: `ERROR`.

This is not a catch-all error event. It does not record expected validation,
routing, authentication, authorization, or CSRF failures; those have their own
response and/or audit paths. It also does not cover failures rejected before
Spring MVC dispatch, such as servlet-container, TLS, proxy, or WAF failures.

| Field | Value or presence | Meaning | ECS alignment |
| --- | --- | --- | --- |
| `event.category` | `["web"]` | Failure occurred during web request processing. | `web` is an allowed ECS category |
| `event.type` | `["error"]` | Error classification. | `error` is an allowed ECS type |
| `event.action` | `process_request` | Request processing operation. | ECS field; project-defined action |
| `event.outcome` | `failure` | Processing failed. | ECS Event field |
| `http.response.status_code` | `500` or upstream 5xx | Response status selected by the exception handler. | ECS HTTP field |
| `url.path` | Request URI path | Target path; must not contain secrets. | ECS URL field |
| `error.type` | Fully qualified exception class | Technical failure classification. | ECS Error field |
| `error.stack_trace` | Exception cause | Stack trace for protected operator access; never returned to the caller. | ECS Error field |
| `http.request.id` | Conditional | Correlates the event with its request when available. | ECS HTTP field |
| `source.ip` | Conditional | Direct peer address when the failure occurs in a request. | ECS Source field |
| `client.ip` | Conditional | Validated end-user client address when the failure occurs in a request. | ECS Client field |
